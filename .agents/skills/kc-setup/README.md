# kc-setup

Навык настраивает целевой проект на использование корпуса знаний: добавляет или
обновляет раздел в `AGENTS.md`, фиксирует папку корпуса и проверяет уже
существующий корпус через навыки коллекции.

Используй его, когда нужно подключить корпус знаний к процессу разработки
проекта, а не просто проверить корпус или добавить новый источник.

Пример:

```text
Настрой этот проект на использование корпуса знаний в AGENTS.md.
```
